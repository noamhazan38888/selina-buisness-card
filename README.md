# Selina Menendez - Digital Business Card

A responsive digital business card for **Selina Menendez**, a fictional DevOps Engineer. The site presents her professional profile, selected projects, contact details, and social links in a clean editorial layout.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Light mode and dark mode using HTML and CSS only
- Semantic HTML structure with accessible labels and links
- Local profile image stored in the `assets` folder
- Local font files stored in `assets/fonts`
- About section with professional background and interests
- Selected projects section with fictional GitHub links
- Contact section with email and phone links
- Smooth navigation between the main sections

## Technologies

- HTML5
- CSS3
- CSS custom properties for theming
- CSS `@font-face` for local fonts
- No JavaScript or external frameworks

## Run Locally

Open `index.html` in a web browser. No installation or build process is required.

## Publish with GitHub Pages

1. Push the project to a public GitHub repository.
2. Open the repository's **Settings** page.
3. Select **Pages** under **Code and automation**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save the settings and open the generated Pages URL.
